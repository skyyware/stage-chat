# Changelog

## 0.1.1 — 2026-10-01

Public Packagist installation replaces private VCS setup. The README includes
an executable request example. Contribution, security, and release guides
describe the local checks and public PR path for humans and agents.

No contract, input limit, failure category, or production dependency changes.

## 0.1.0 — 2026-10-01

Initial MIT contract for a bounded stateless chat request and one final response.
Applications supply trusted instructions, untrusted context, and user/assistant
messages. Providers expose cancellation and stable, content-free failures.
The package has no storage, network client, provider dependency, or tools.
